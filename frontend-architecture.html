useChatSession SSE 事件流

sequenceDiagram
  participant UI as MessageList
  participant Hook as useChatSession
  participant SSE as /api/chat SSE
  participant API as api client

  UI->>Hook: submit(message)
  Hook->>API: POST /messages → 立即返回
  API-->>Hook: {session_id, turn_id}
  Hook->>Hook: setTurnState("running")

  loop SSE 事件流
    SSE->>Hook: event: message
    Hook->>UI: setMessages(append)
    SSE->>Hook: event: knowledge_citation
    Hook->>Hook: citations[turn_id] = list
    SSE->>Hook: event: trace (phase)
    Hook->>UI: ExecutionRecord 进度更新
    SSE->>Hook: event: awaiting_user
    Hook->>Hook: setTurnState("awaiting_user")
    SSE->>Hook: event: finish
    Hook->>Hook: setTurnState("completed")
  end
